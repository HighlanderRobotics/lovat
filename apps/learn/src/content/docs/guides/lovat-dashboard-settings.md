## Data Sourcing

The Use Data from Teams setting will be used when creating the statistics you see. You can select only your team, all teams, or a specific selection of any number of teams.

Similarly, the Use Data from Tournaments setting will be used for your statistics.

You can also set which tournament you are at, which is important for match and scouter schedules.

## Reset App and Delete Settings

This setting will delete all of your saved settings and reset the app to its initial state.
